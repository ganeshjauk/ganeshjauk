## 🚀 Featured Project: E-commerce Data Pipeline

> **Medallion Architecture (Bronze → Silver → Gold) on AWS**

```text
 RDBMS / FTP  ──►  Glue + NiFi  ──►  S3 (Bronze)  ──►  Spark on EMR  ──►  S3 (Silver → Gold)  ──►  Redshift + MongoDB
                                                           ▲
                                                  Orchestrated by Airflow
```

| Layer | What I did |
|:--|:--|
| 📥 **Ingestion** | Pulled structured and unstructured data from RDBMS and FTP into S3 using AWS Glue and Apache NiFi |
| ⚙️ **Processing** | Tuned Spark jobs on EMR with dynamic resource allocation and optimized executor/core configs to cut shuffle overhead |
| ⏱️ **Orchestration** | Scheduled, fault-tolerant workflows with Apache Airflow |
| ✅ **Data Quality** | Schema validation, referential integrity checks, anomaly detection |
| 📤 **Serving** | Loaded processed data into Redshift and MongoDB for analytics and real-time use cases |

`AWS S3` `Glue` `EMR` `Redshift` `MongoDB` `Apache Spark` `Apache NiFi` `Apache Airflow`
